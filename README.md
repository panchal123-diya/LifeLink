# 🚑 LifeLink – Emergency Healthcare Network

LifeLink is a healthcare emergency platform built with **Python Django** that helps users quickly find hospital beds, blood availability, and nearby blood donors during emergencies.

🌟 Features
🏥 Hospital Bed Management
Search hospitals by city and bed type
ICU, Oxygen, and General bed availability
Real-time bed updates
Hospital dashboard for inventory management

🩸 Blood Availability System
Search blood banks by city and blood group
Real-time blood stock visibility
Verified blood bank listings

❤️ Blood Donor Network
Donor registration and profile management
Eligibility checking based on last donation date
Smart donor matching system
Emergency blood request notifications

🚨 Emergency Request System
Create blood requests
Create hospital bed requests
Live request tracking
Request approval and rejection workflow

🔐 Authentication & Security
User Registration & Login
Hospital Staff Accounts
Blood Bank Accounts
Donor Accounts
Google OAuth Login
Role-based Access Control

📊 Dashboards & Analytics
Hospital Dashboard
Blood Bank Dashboard
Donor Dashboard
Request Statistics
Interactive Charts

## Tech Stack

* Python Django
* SQLite
* Bootstrap 5
* JavaScript
* Chart.js

## Run Project

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Open: `http://127.0.0.1:8000`
